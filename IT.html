Infrastruktuuri projekt

Väike-ettevõtte IT-taristuteenused (Windows Server)

Ehitasin ja konfigureerisin nullist toimiva, skaleeritava ning turvalise ettevõtte võrgutaristu. Projekt hõlmas keskset kasutajahaldust, failiteenuseid, võrguruutingut ja virtualiseerimist, tagades ärikriitiliste teenuste kõrge kättesaadavuse ning turvalise kaughalduse võimekuse.

Windows Server 2025 Active Directory (AD DS) Hyper-V DNS & DHCP RRAS & VPN IIS Web Server Group Policy (GPO)
Joonis 1: Ettevõtte võrgutopoloogia ja serverite arhitektuur

Teostatud tööd ja omandatud oskused

  • Keskne domeenihaldus: Paigaldasin Active Directory (DC1 ja server-core DC2) FSMO rollide ja DNS teenustega, luues turvalise domeenikeskkonna (%perenimi%.infra).
  • Virtualiseerimine: Seadistasin Hyper-V hüperviisori eraldatud virtuaalmasinate (DC2, WEB) käitamiseks.
  • Võrguteenused & Turvalisus: Konfigureerisin ruutingu (RRAS), DHCP serveri, tulemüüri ning SSTP/L2TP VPN-ühendused turvaliseks kaugtööks.
  • Veebi- ja failiserverid: Paigaldasin IIS veebiserveri ja klassikalise SMB failiserveri (FS) ettevõtte andmete tsentraalseks hoiustamiseks.
  • Tsentraalne haldus: Juhtisin Windows Server CORE versioone läbi Windows 11 haldusmasina (MGMT) ja RSAT tööriistade.
